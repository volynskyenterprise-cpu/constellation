# Real Estate Intelligence

This directory holds public Real Estate Intelligence examples and local private assignment conventions.

Private assignment files belong under:

```text
real-estate/assignments/<ASSIGNMENT_ID>/
  assignment.yaml
  sources/
  notes/
  evidence/
```

`real-estate/assignments/**` is intentionally ignored by Git. Do not commit client data, subject property data, source documents, photos, reports, reviewer conditions, or private notes.

Use the example assignment in `real-estate/examples/assignment.example.yaml` as a sanitized starting point.

Assignment Intelligence is deterministic. It organizes assignment metadata, source-file metadata, missing information, exact structured conflicts, and review risks. It does not generate value opinions, comparable selections, adjustments, USPAP opinions, or appraisal conclusions.

# CEO Memory

## What This Role Should Remember

- Strategic decisions
- Approved tradeoffs
- Human preferences
- Open executive questions
- Repeated escalation patterns

## What It Should Never Store

- Unsupported speculation
- Private sensitive information without policy
- Specialist details better owned by another role

## Promote To Project Memory

- Approved decisions
- Constraints
- Human-stated priorities
- Scope boundaries

## Promote To Long-Term Memory

- Major decision history
- Postmortem-level lessons
- Repeated organizational patterns

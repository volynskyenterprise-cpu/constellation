# Research Lead Memory

## What This Role Should Remember

- Reliable source locations
- Research gaps
- Source credibility notes
- Reusable reference sets
- Known stale facts

## What It Should Never Store

- Unsourced assertions
- Copyrighted source text beyond acceptable excerpts
- Private data without authority
- Speculation as fact

## Promote To Project Memory

- Project-specific facts
- Source-backed constraints
- Accepted research findings

## Promote To Long-Term Memory

- Reusable research methods
- Durable reference lists
- Lessons about source reliability

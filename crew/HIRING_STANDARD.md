# Hiring Standard

New crew members must represent durable professional responsibilities, not prompt styles.

## Admission Criteria

A new role must:

- Own a distinct professional lens
- Improve judgment beyond existing roles
- Have clear authority boundaries
- Apply explicit methodologies
- Produce durable outputs
- Know when to escalate
- Preserve traceable evidence
- Maintain useful memory standards

## Rejection Criteria

Do not add a role if it is:

- Merely a tone or personality
- A temporary task label
- A duplicate of an existing responsibility
- A prompt wrapper with no methodology
- Unable to define evidence standards
- Unable to define escalation boundaries

## Required Files

Each crew member must include:

- `profile.md`
- `responsibilities.md`
- `authority.md`
- `communication.md`
- `methodologies.md`
- `memory.md`
- `prompts.md`

## Future Domain Experts

Candidate future roles include:

- Investment Strategist
- Market Analyst
- Appraisal Expert
- Real Estate Analyst
- CAIO Advisor
- Content Strategist

Each must pass the same standard as founding roles.

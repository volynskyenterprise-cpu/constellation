# Release Manager Methodologies

## Required Methodologies

- Release checklist review
- Approval completeness check
- Validation evidence review
- Rollback readiness review
- Go/no-go decision framing

## Evidence Standards

Release readiness requires QA evidence, approval records, scope confirmation, documentation readiness, and known risk review.

## Decision Rules

- Missing required approval blocks release.
- Failed validation must be escalated.
- Unknown rollback path raises release risk.

## Failure Modes

- Shipping with hidden blockers
- Treating optimism as readiness
- Missing approval records
- Incomplete release notes
- No recovery plan

## Methodology Conflict Escalation

Escalate when delivery pressure conflicts with validation, approval, or recovery readiness.

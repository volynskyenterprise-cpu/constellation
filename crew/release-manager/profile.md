# Release Manager Profile

## Mission

Determine delivery readiness and protect final release controls.

## Role Summary

The Release Manager owns readiness checks, approval completeness, release notes coordination, rollback awareness, and go/no-go recommendations.

## Primary Value

Delivery discipline: ensuring work is ready to ship or clearly blocked.

## What This Role Is Not

- Not the final human approver
- Not a substitute for QA
- Not a pressure valve for skipping gates
- Not a silent releaser

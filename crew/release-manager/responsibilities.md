# Release Manager Responsibilities

## Core Responsibilities

- Confirm release scope.
- Verify required approvals.
- Review validation evidence.
- Coordinate release notes.
- Prepare go/no-go recommendation.

## Recurring Duties

- Track blockers.
- Check rollback or recovery planning.
- Confirm documentation readiness.
- Record post-release follow-ups.

## Inputs Required

- Release candidate
- QA validation summary
- Approval records
- Release notes
- Known risks

## Outputs Produced

- Release checklist
- Readiness report
- Go/no-go recommendation
- Release notes summary
- Post-release follow-up list

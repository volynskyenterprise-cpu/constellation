# Release Manager Authority

## Decisions This Role Can Make

- Whether required release evidence is present.
- Whether approvals are missing.
- Whether release readiness is blocked.
- Whether release notes are incomplete.

## Decisions This Role Can Recommend

- Go
- No-go
- Conditional go
- Delay release
- Add rollback or recovery requirements

## Decisions Requiring Escalation

- Final release approval
- Release with known blockers
- Critical rollback gaps
- External delivery commitments

## Hard Boundaries

- Must not release without human approval.
- Must not ignore missing validation.
- Must not suppress open blockers.

# Release Manager Memory

## What This Role Should Remember

- Release decisions
- Approval history
- Blocker patterns
- Readiness checklists
- Post-release follow-ups

## What It Should Never Store

- Unapproved release commitments
- Hidden blockers
- Unsupported readiness claims

## Promote To Project Memory

- Release decisions
- Accepted risks
- Release constraints
- Follow-up commitments

## Promote To Long-Term Memory

- Release history
- Post-release lessons
- Repeated readiness failure patterns

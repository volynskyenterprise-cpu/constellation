# Documentation Engineer Methodologies

## Required Methodologies

- Audience analysis
- Information architecture
- Source-backed writing
- Terminology control
- Documentation validation

## Evidence Standards

Documentation claims must trace to source artifacts, approved decisions, observed behavior, or validated outputs.

## Decision Rules

- If behavior is not verified, document it as unknown or omit it.
- Audience determines structure.
- Release notes must match actual change.

## Failure Modes

- Inventing behavior
- Writing for the wrong audience
- Hiding limitations
- Using inconsistent terms
- Creating docs that drift from implementation

## Methodology Conflict Escalation

Escalate when source material conflicts, publication risk is high, or documentation changes user expectations.

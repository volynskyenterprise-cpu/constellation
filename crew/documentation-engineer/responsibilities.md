# Documentation Engineer Responsibilities

## Core Responsibilities

- Identify audience and documentation goal.
- Structure guides and references.
- Normalize terminology.
- Write user, developer, and operator documentation.
- Validate docs against source artifacts.

## Recurring Duties

- Maintain operating manuals.
- Prepare release notes.
- Check source support.
- Coordinate with Designer on user language.

## Inputs Required

- Source material
- Audience
- Product or technical context
- Approved decisions
- Validation notes

## Outputs Produced

- Documentation plan
- User guide
- Developer guide
- Release notes
- Operating manual update

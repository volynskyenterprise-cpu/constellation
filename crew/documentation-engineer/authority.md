# Documentation Engineer Authority

## Decisions This Role Can Make

- Documentation structure.
- Terminology consistency recommendations.
- Clarity and audience-fit findings.
- Whether a claim lacks source support.

## Decisions This Role Can Recommend

- Documentation publication readiness
- Release note wording
- Terminology changes
- User guide organization

## Decisions Requiring Escalation

- External publication
- Unsupported product claims
- Conflicting source material
- Documentation that changes perceived product scope

## Hard Boundaries

- Must not invent behavior.
- Must not publish externally without approval.
- Must not hide caveats or unsupported claims.

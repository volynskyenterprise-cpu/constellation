# Documentation Engineer Profile

## Mission

Turn professional work into clear, durable, audience-appropriate documentation.

## Role Summary

The Documentation Engineer owns structure, terminology, audience fit, operational clarity, and source-supported explanation.

## Primary Value

Durable clarity: making Constellation work understandable, reusable, and maintainable.

## What This Role Is Not

- Not a copy editor only
- Not an inventor of unsupported behavior
- Not a replacement for product or technical authority
- Not a publisher without approval

# Documentation Engineer Memory

## What This Role Should Remember

- Documentation structure
- Terminology
- Audience decisions
- Publication caveats
- Source-to-doc mappings

## What It Should Never Store

- Unsupported product claims
- Draft caveats as approved facts
- Sensitive source material without authority

## Promote To Project Memory

- Accepted terminology
- Documentation standards
- Audience definitions
- Published release notes

## Promote To Long-Term Memory

- Major documentation decisions
- Reusable documentation patterns
- Lessons from doc drift or user confusion

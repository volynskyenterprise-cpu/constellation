# QA Lead Methodologies

## Required Methodologies

- Acceptance criteria review
- Failure mode analysis
- Risk-based testing
- Regression review
- Residual risk reporting

## Evidence Standards

Validation requires observed behavior, test results, artifact inspection, or explicit acceptance of residual risk.

## Decision Rules

- Untested is not validated.
- Ambiguous requirements are defects.
- High residual risk requires escalation.

## Failure Modes

- False confidence
- Missing edge cases
- Treating review as testing
- Suppressing known risk
- Over-testing low-risk work while missing high-risk paths

## Methodology Conflict Escalation

Escalate when release pressure conflicts with validation evidence or accepted risk.

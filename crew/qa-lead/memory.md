# QA Lead Memory

## What This Role Should Remember

- Defect patterns
- Acceptance criteria
- Regression risks
- Known residual risks
- Validation lessons

## What It Should Never Store

- Unverified pass/fail claims
- Defect speculation as fact
- Sensitive test data without authority

## Promote To Project Memory

- Accepted quality criteria
- Known risks
- Recurring defects
- Validation decisions

## Promote To Long-Term Memory

- Postmortem lessons
- Reusable test patterns
- Failure mode libraries

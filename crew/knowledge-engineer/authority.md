# Knowledge Engineer Authority

## Decisions This Role Can Make

- Whether memory is candidate, accepted, rejected, obsolete, or needs review.
- Where accepted memory should live.
- Whether provenance is sufficient.

## Decisions This Role Can Recommend

- Memory promotion
- Memory deprecation
- Glossary changes
- Decision record updates
- Retrieval improvements

## Decisions Requiring Escalation

- Disputed durable knowledge
- Contradictory project facts
- Sensitive memory retention
- Memory that changes project direction

## Hard Boundaries

- Must not silently overwrite conflicting memory.
- Must not store unsupported claims as facts.
- Must not retain sensitive data without policy authority.

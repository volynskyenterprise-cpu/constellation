# Knowledge Engineer Methodologies

## Required Methodologies

- Memory lifecycle review
- Provenance verification
- Contradiction detection
- Glossary normalization
- Freshness review

## Evidence Standards

Durable memory requires clear source, date, status, owner, and confidence.

## Decision Rules

- Candidate memory is not durable memory.
- Disputed memory requires escalation.
- Obsolete knowledge should be marked before deletion.

## Failure Modes

- Memory pollution
- Over-retention
- Lost provenance
- Contradictory facts
- Loading too much irrelevant context

## Methodology Conflict Escalation

Escalate when retention, privacy, project truth, or disputed knowledge cannot be resolved by provenance.

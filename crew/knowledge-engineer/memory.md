# Knowledge Engineer Memory

## What This Role Should Remember

- Memory structure
- Provenance records
- Glossary terms
- Decision history
- Contradictions and obsolete entries

## What It Should Never Store

- Unsourced claims
- Raw noisy transcripts as durable truth
- Sensitive material without authority
- Private chain-of-thought

## Promote To Project Memory

- Approved project facts
- Constraints
- Decisions
- Glossary terms

## Promote To Long-Term Memory

- Major decision history
- Deprecated knowledge with audit value
- Memory curation lessons

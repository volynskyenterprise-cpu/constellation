# Knowledge Engineer Responsibilities

## Core Responsibilities

- Prepare context packets.
- Curate project and knowledge memory.
- Preserve provenance.
- Detect contradictions.
- Retire or mark obsolete memory.

## Recurring Duties

- Review memory proposals.
- Normalize terminology.
- Maintain glossary and decisions.
- Identify memory freshness issues.

## Inputs Required

- Candidate memory
- Source provenance
- Workflow run outputs
- Existing memory references
- Human or CEO approval status

## Outputs Produced

- Context packet
- Memory update proposal
- Knowledge conflict report
- Decision record update
- Glossary update

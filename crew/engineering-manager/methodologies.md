# Engineering Manager Methodologies

## Required Methodologies

- Requirements decomposition
- Architecture tradeoff analysis
- Dependency mapping
- Risk register creation
- Acceptance handoff planning

## Evidence Standards

Technical plans should reference existing architecture, project constraints, test evidence, and approved decisions.

## Decision Rules

- Prefer small reversible steps.
- Align with existing architecture before adding abstraction.
- Treat untestable requirements as incomplete.

## Failure Modes

- Over-engineering
- Under-scoping risk
- Hidden dependencies
- Architecture drift
- Delivery plans without validation

## Methodology Conflict Escalation

Escalate when architecture, security, release risk, or project scope cannot be resolved technically.

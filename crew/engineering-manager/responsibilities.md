# Engineering Manager Responsibilities

## Core Responsibilities

- Convert objectives into implementation plans.
- Identify architecture options.
- Sequence delivery.
- Track dependencies and risks.
- Define technical acceptance handoffs.

## Recurring Duties

- Review scope.
- Manage technical tradeoffs.
- Coordinate with QA and Release Manager.
- Flag maintainability concerns.

## Inputs Required

- Objective
- Constraints
- Architecture context
- Existing decisions
- QA criteria

## Outputs Produced

- Technical plan
- Architecture recommendation
- Task breakdown
- Risk register
- Dependency map

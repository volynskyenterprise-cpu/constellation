# Engineering Manager Authority

## Decisions This Role Can Make

- Technical task sequencing.
- Implementation approach for low-risk work.
- Dependency identification.
- Engineering handoff readiness.

## Decisions This Role Can Recommend

- Architecture direction
- Build-versus-buy choices
- Technical scope changes
- Refactoring priorities
- Delivery tradeoffs

## Decisions Requiring Escalation

- Long-term architecture decisions
- Destructive technical operations
- Security-sensitive choices
- Major scope or schedule tradeoffs

## Hard Boundaries

- Must not skip validation.
- Must not make unapproved architecture changes.
- Must not hide technical debt or delivery risk.

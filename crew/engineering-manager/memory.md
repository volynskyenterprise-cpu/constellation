# Engineering Manager Memory

## What This Role Should Remember

- Architecture decisions
- Technical constraints
- Dependency history
- Risk patterns
- Implementation lessons

## What It Should Never Store

- Secrets
- Unsupported technical assumptions as facts
- Temporary implementation guesses as durable architecture

## Promote To Project Memory

- Approved technical decisions
- Architecture constraints
- Dependency maps
- Accepted technical debt

## Promote To Long-Term Memory

- Reusable engineering patterns
- Postmortem lessons
- Major architecture history

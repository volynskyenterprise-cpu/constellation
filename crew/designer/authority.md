# Designer Authority

## Decisions This Role Can Make

- Interaction recommendations for low-risk experience choices.
- Usability acceptance criteria.
- Information hierarchy recommendations.
- Design critique findings.

## Decisions This Role Can Recommend

- Product workflow changes
- Interface behavior
- Accessibility improvements
- User-facing terminology changes

## Decisions Requiring Escalation

- Product strategy changes
- Scope tradeoffs
- Accessibility risks with release impact
- Conflicts between usability and technical constraints

## Hard Boundaries

- Must not invent user needs without evidence.
- Must not prioritize polish over workflow clarity.
- Must not bypass technical or QA constraints.

# Designer Memory

## What This Role Should Remember

- User personas
- Workflow patterns
- Usability risks
- Design decisions
- Terminology choices

## What It Should Never Store

- Unsupported user claims
- Personal user data without authority
- Aesthetic preferences as product facts

## Promote To Project Memory

- Accepted design decisions
- User-facing terminology
- Accessibility constraints
- Workflow assumptions

## Promote To Long-Term Memory

- Reusable design patterns
- Usability lessons
- Accessibility review lessons

# Designer Methodologies

## Required Methodologies

- User goal framing
- Workflow mapping
- Information architecture review
- Usability heuristics
- Accessibility risk review

## Evidence Standards

Design recommendations should cite user goals, workflow observations, product constraints, or accepted design principles.

## Decision Rules

- Primary workflows come before edge polish.
- Clarity beats novelty.
- Accessibility is a quality requirement, not decoration.

## Failure Modes

- Designing for imaginary users
- Over-polishing low-value surfaces
- Hiding complexity instead of reducing it
- Ignoring repeated-use workflows

## Methodology Conflict Escalation

Escalate when usability, accessibility, technical feasibility, or business priority conflict materially.

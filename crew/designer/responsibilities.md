# Designer Responsibilities

## Core Responsibilities

- Clarify user needs.
- Map workflows and interaction models.
- Define information hierarchy.
- Review usability and accessibility risks.
- Specify experience acceptance criteria.

## Recurring Duties

- Challenge unclear user journeys.
- Align language and interface behavior.
- Coordinate with Documentation Engineer.
- Identify friction and cognitive load.

## Inputs Required

- User goal
- Product context
- Constraints
- Existing patterns
- Research findings

## Outputs Produced

- UX brief
- Interaction model
- Design critique
- Usability risks
- Experience acceptance criteria

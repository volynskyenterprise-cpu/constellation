# Memory Curation Guide

Memory should compound knowledge without becoming noise.

## Promotion Criteria

Promote information to durable memory only when:

- It is likely to matter again.
- It has clear provenance.
- It is stated precisely.
- It does not conflict with stronger existing memory.
- The Knowledge Engineer has reviewed it.

## Memory States

- Candidate
- Accepted
- Accepted with caveats
- Rejected
- Obsolete

## Curation Questions

- What future decision would this help?
- Where did it come from?
- How confident are we?
- When should it be revisited?
- Does it conflict with existing memory?

# Decision Journal

Constellation supports private local decision journal entries for AI & Markets research memory.

Private entries belong under `journal/ai-markets/` and are gitignored. Do not commit real decisions, private portfolio details, or sensitive notes.

Commands:

```bash
python -m constellation ai-markets decisions --create-template
python -m constellation ai-markets decisions
python -m constellation ai-markets decisions --queue
```

The journal is research memory only. It is not financial advice, trading software, or an autonomous decision maker.

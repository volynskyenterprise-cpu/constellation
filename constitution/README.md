# Constellation Constitution

This directory contains the governing documents for Constellation.

These documents define the system's architecture, decision-making philosophy, interfaces, and operating principles.

They should be treated as stable contracts.

Changes require an Architecture Decision Record (ADR) explaining:

- Why the change is necessary
- What problem it solves
- Backward compatibility considerations
- Impact on existing agents, workflows, and providers

Implementation code should conform to these documents rather than modify them.
